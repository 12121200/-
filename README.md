Расположение элементов — по алфавиту буквенных обозначений, внутри группы по возрастанию номеров, однотипные можно объединять.
Конденсаторы — указывают слово «Конденсатор», тип, ёмкость с допуском, обозначение ГОСТ/ТУ.
Резисторы — указывают слово «Резистор», тип, мощность, сопротивление с допуском, обозначение ГОСТ/ТУ.
Полупроводниковые приборы — указывают наименование (диод, транзистор и т.д.), тип по документации, обозначение ГОСТ/ТУ.
