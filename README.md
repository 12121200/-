KiCAD — программа для создания принципиальных схем и печатных плат.Рамку меняют через Page Settings, выбирая нужный шаблон или редактируя его в Page Layout Editor.Используются основные компоненты: резисторы, конденсаторы, диоды, транзисторы, микросхемы, разъёмы, источники питания.Компоненты размещают через инструмент Add Symbol (клавиша A).Соединение выполняют проводником через Place Wire (клавиша W).Да, проверка выполняется с помощью ERC (Electrical Rules Check).
