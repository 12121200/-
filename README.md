1. Правила наименования компонентов
Буква — вид элемента (R — резистор, C — конденсатор, VD — диод, VT — транзистор, DD — микросхема), цифра — порядковый номер (R1, C2, VT1).
2. Расположение обозначений
Рядом с элементом (справа или сверху), нумерация — слева направо, сверху вниз.
3. Правила оформления по ЕСКД
Стандартные условные обозначения;
позиционные обозначения у каждого элемента;
линии связи прямые, без лишних изломов;
равномерное расположение элементов;
перечень элементов (спецификация);
основная надпись (штамп).
4. Пример обозначений
R1 — резистор, C2 — конденсатор, VT1 — транзистор.
